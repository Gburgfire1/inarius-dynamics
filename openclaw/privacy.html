Inarius Mail Agent Privacy Policy

Inarius Mail Agent is operated by Inarius Dynamics / Nicholas Stefany. This page explains how that private tool handles Gmail data.

Effective: November 15, 2026

What Inarius Mail Agent accesses

Inarius Mail Agent accesses Gmail only to send and read mail for the account owner's own automation. It is a private tool used only by its owner.

Selling and sharing

No data is sold, or shared with or transferred to third parties.

OAuth tokens

OAuth tokens are stored locally on the owner's own machine.

Revoking access

Users can revoke access anytime at https://myaccount.google.com/permissions.

Google user data

Inarius Mail Agent's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google user data is not used for advertising, not used to train generalized AI/ML models, and not read by humans except with the owner's consent, for security, or as required by law.
